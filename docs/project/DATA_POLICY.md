# Data and artifact policy

The migration preserves all discovered data, but preservation does not mean every generated byte belongs in normal Git history.

## Repository source

Track application source, documentation, configuration, tests, small reviewed fixtures, approved brand assets and the provenance needed to reproduce a result.

## Local user and runtime data

Keep project sessions, creative documents, brand-library databases, task records and personal work outside the normal source tree. Back them up independently with checksums. A private repository may later store a reviewed encrypted or release archive, but these files are not mixed into application commits.

## Generated and reproducible output

Build directories, rendered videos, temporary frames, audio intermediates, browser profiles, caches, package installations and downloaded model/toolchain files remain ignored. Preserve important outputs in a release/evidence archive rather than source commits.
