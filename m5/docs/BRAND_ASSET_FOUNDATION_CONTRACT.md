# Separate Brand & Asset foundation contract v1

Defined before introducing persistence. Authorizes no creative@1/history/R1 changes or creative integration. New application-owned SQLite store: .runtime/studio-ui/brand-library/library.sqlite3. Unit/browser fixtures use explicitly selected fresh in-workspace roots. No migration/import of databases; unknown application/user versions are refused. GET on absent store returns empty without creating it. A mutation explicitly initializes the separate library. No store pointer is added to existing projects or Visual ownership markers.

Canonical record bytes: UTF-8 JSON, sorted object keys, compact separators, ensure_ascii=False, allow_nan=False; SHA-256 identity. No Unicode normalization. This is a separate Python-owned metadata contract, not a reinterpretation of R1 canonicalization.

Asset record: {type:'asset',id:UUID,name:string,kind:logo|image|font|template,sha256:hex64,bytes:positive_integer,provenance:{owner,source,license}}. Name is a plain filename/label without slash, backslash or NUL. Registration accepts explicitly selected opaque bytes (max 8 MiB), hashes and retains them, deduplicates byte storage by hash, and never decodes, parses, previews binary content, loads fonts or executes templates. Declared kind is unverified. Browser metadata preview contains no binary-serving URL. Registration is not rights clearance or Gate A qualification.

Rights event: {type:'rights',id:UUID,asset_id:UUID,previous:hash|null,status:unknown|granted|denied,authority:string,evidence:string,scopes:list,destinations:list,expires:UTC timestamp|null}. Allowed scopes internal_preview, commercial_design, redistribute, template_use, font_embed. Destinations poster, reel, library_metadata. Grant requires nonempty authority/evidence, scopes/destinations and exact YYYY-MM-DDTHH:MM:SSZ expiry. Non-grants must have empty scope/destination lists and null expiry. Decision events append; optimistic expected_rights hash guards concurrency. A denied event revokes current eligibility without rewriting history. Missing/unknown/denied/expired/out-of-scope records deny. Labels are assertions by a trusted local actor, not authenticated authority or external verification. Software/file availability never establishes media or trademark rights.

Brand record: {type:'brand',brand_id:UUID,revision:positive_integer,parent:hash|null,state:draft|approved,reviewer:string,approved_at:UTC|null,payload:{name,colors,typography:{english,telugu},mandatory_rules,preferences,inspiration,notes,asset_ids},bindings:list}. Colors: unique #RRGGBB strings; only approved in an approved version. Rule/preference/inspiration entries are bounded plain-text declarations in distinct arrays, not executable or operationally enforced project rules. Typography fields are preferences only; registered fonts never load. Payload must have exact fields, max 16 colors, 32 entries per list, 64 asset IDs. Notes max 2000; short text max 256. Every save appends a new immutable draft from expected_head; no update in place. Approve appends an approved version from the current draft after explicit acknowledgement/reviewer and current scoped asset checks; snapshots pin asset SHA and rights event hashes. Approved versions cannot be reapproved or edited; Create revision copies their payload into a new draft. All revisions stay viewable by hash. Independent brands have independent heads. No silent rename/version reinterpretation.

Approval scope: manual library metadata review only, requiring current internal_preview/library_metadata asset clearance. Every other scope/destination still requires an independent eligibility query. Any changed rights event hash makes an approved binding stale even after regrant; explicit revision/reapproval is required. Historical approval bytes remain immutable; current eligibility is recomputed from latest rights events and can become blocked. Creative use is always disabled until separately authorized integration; brand approval never approves a poster/export.

SQLite application_id 0x42524131, user_version 1; rollback journal DELETE, synchronous FULL, temp_store MEMORY, timeout 0 (busy refuses; no retry). Separate OS flock protects all library operations. Append-only records and blob tables have no-update/no-delete triggers; mutable heads are pointers only. Strict canonical/hash checks on read, schema/version checks and SQLite quick_check reject corrupted/unknown stores. SQL transaction commits blob/asset/rights together. Exceptions rollback. Limits: 100 assets, 1000 total records, 32 MiB distinct opaque bytes, 64 MiB SQLite main database cap; this is a library limit, not a Gate A resource qualification. Journal/filesystem overhead and physical power-loss guarantees are not proven. Symlinks/hardlinks/special files and outside-workspace store roots are refused. No automatic cleanup, overwrite, repair, migration or evidence deletion.

Reuses installed Python sqlite3/SQLite. Upstream SQLite deliverable code is public domain; configure/build scripts may have separate terms. Python bindings/runtime retain PSF/bundled obligations. No new package/runtime binary/source acquired; complete runtime/build-source/native-license closure remains open. Official references: https://docs.python.org/3/library/sqlite3.html ; https://www.sqlite.org/copyright.html ; https://www.sqlite.org/atomiccommit.html .
